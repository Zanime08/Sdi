# SDI · Редактор персонажей

Учебное SDI-приложение (Single Document Interface) на WPF / C# по дисциплине «Системы диалогового интерфейса».
Создано по образцу репозитория [MishanyaGG/SDIproject](https://github.com/MishanyaGG/SDIproject),
но под своё задание — **приложение для редактирования/просмотра персонажей**.

> **Совместимость:** проект в **SDK-style** под **.NET 8** (`net8.0-windows`, WPF) —
> открывается и собирается в **Visual Studio 2022** (с рабочей нагрузкой .NET Desktop).
> Требуется установленный **.NET 8 SDK**.

## Задание (Практика SDI)
- Разрешение окна **1920 × 1080**.
- Слева — вертикальная полоска команд:
  - **1.1 Список персонажей** — на рабочем экране список персонажей с характеристиками.
  - **1.2 Покупка персонажей** — на рабочем экране список персонажей для покупки.
- Кнопки команд выполнены в виде картинок (логотипов).
- Контент статический, разбит на фреймы (`Grid`).
- Стили вынесены в отдельный файл.
- Задана цветовая палитра.

## Структура
```
App.xaml / App.xaml.cs          — точка входа, подключение палитры на уровне приложения
MainWindow.xaml / .cs           — главное окно: левая панель команд + Frame
MainWindowResources.xaml        — стили кнопок-команд (отдельный файл)
Palette.xaml                    — цветовая палитра (отдельный файл)
CharactersListPage.xaml / .cs   — страница 1.1: список персонажей с характеристиками
ShopPage.xaml / .cs             — страница 1.2: покупка персонажей
SettingsPage.xaml / .cs         — страница настроек (доп. команда)
Assets/Image/                   — логотипы команд (characters.png, shop.png, settings.png)
Sdi.csproj / Sdi.sln           — проект WPF под .NET 8 (SDK-style, net8.0-windows)
```

## Запуск
Открыть `Sdi.sln` в **Visual Studio 2022**, убедиться что установлен **.NET 8 SDK**,
и нажать **Запуск** (F5). Целевая платформа — `net8.0-windows`.

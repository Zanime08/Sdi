# SDI · Редактор персонажей

Учебное SDI-приложение (WPF / C#) по дисциплине «Системы диалогового интерфейса».
Сделано по образцу [MishanyaGG/SDIproject](https://github.com/MishanyaGG/SDIproject),
но под задание — **приложение для просмотра/покупки персонажей**.

## Задание
- Разрешение **1920 × 1080**.
- Слева — вертикальная полоска команд (кнопки-картинки):
  - **1.1 Список персонажей** — список персонажей с характеристиками.
  - **1.2 Покупка персонажей** — список персонажей для покупки.
- Кнопки команд — в виде картинок (логотипов).
- Контент статический: две страницы (`Page`) открываются внутри одного `Frame`.
- Стили — в отдельном файле (`MainWindowResources.xaml`).
- Цветовая палитра — `Palette.xaml`.

## Структура
```
App.xaml / App.xaml.cs          — запуск, подключение цветов и стилей
MainWindow.xaml / .cs           — окно 1920×1080, левая панель + Frame
MainWindowResources.xaml        — стили команд (отдельный файл)
Palette.xaml                    — цветовая палитра
CharactersListPage.xaml / .cs   — 1.1 список персонажей
ShopPage.xaml / .cs             — 1.2 покупка персонажей
Assets/Image/                   — логотипы команд
Sdi.csproj / Sdi.sln            — проект WPF под .NET 8
```

## Запуск
Открыть `Sdi.sln` в Visual Studio 2022 (с .NET 8 SDK) и нажать F5.

## Цвета из задания
В `Palette.xaml` сохранены все 20 оттенков с образца:
- основной — жёлтый (`#FFE800`);
- вторичный A — зелёный (`#00AF64`);
- вторичный B — оранжевый (`#FF4900`);
- дополнительный — фиолетовый (`#530FAD`).

Светлые жёлтые оттенки используются для фона и карточек, фиолетовые —
для меню и текста, тёмно-зелёный — для имён, тёмно-оранжевый — для цен.
Стили заголовков, карточек и подписей находятся в `MainWindowResources.xaml`.
Оба словаря подключены в `App.xaml`, поэтому доступны и внутри страниц `Frame`.
Содержимое магазина остаётся статическим: надпись «Купить» не выполняет покупку.

## Как устроен код (простое объяснение)
1. `App.xaml` открывает `MainWindow` и подключает цвета и стили.
2. `InitializeComponent()` создаёт элементы из соответствующего XAML-файла.
   Этот метод предоставляет WPF, писать его вручную не нужно.
3. При запуске `FrameArea.Content = new CharactersListPage();` создаёт страницу
   со списком персонажей и показывает её справа от меню.
4. У каждой кнопки свой обработчик `Click` в `MainWindow.xaml.cs`:
   `CharactersButton_Click` показывает список, `ShopButton_Click` — магазин.
   Обработчик — обычный метод, который WPF вызывает при нажатии кнопки.
5. `FrameArea.Content` — содержимое рабочей области, `new` создаёт объект страницы.
   Новых окон программа не открывает.

Вместо общего обработчика с `Tag`, поиском родителя и преобразованиями типов
используются два отдельных коротких метода. Собственный шаблон кнопки и код
переключения подсветки выбранного пункта убраны; обе кнопки оформлены одинаково.

### Основные обозначения XAML
- `Grid` — сетка со строками и колонками, `StackPanel` — элементы друг за другом.
- `Border` — рамка карточки, `TextBlock` — текст, `Image` — картинка.
- `Margin` — внешний отступ, `Padding` — внутренний.
- `Background` — фон, `Foreground` — цвет текста.
- `x:Name` — имя элемента для обращения к нему из C#.
- `x:Key` — имя ресурса, например цвета или стиля.
- `StaticResource` — взять готовый ресурс по имени. Цвета во время работы не меняются,
  поэтому более сложный `DynamicResource` здесь не нужен.
- `Style` — набор настроек элемента; `Setter` задаёт одну настройку.

В `Palette.xaml` каждый цвет записан сразу как кисть `SolidColorBrush`,
без отдельного слоя ресурсов `Color`. Все 20 оттенков сохранены; часть оставлена
в палитре про запас. Комментарии на русском есть в C#, XAML и файле проекта.
